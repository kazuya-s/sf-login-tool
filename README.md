# KS SF Login

Salesforce の複数組織へのログインをワンクリックで行える Chrome 拡張機能です。

[English](./README.en.md)

---

## 特徴

- **ワンクリックログイン** — ログインページを自動で開き、ID・パスワードを自動入力してログインボタンをクリック
- **複数組織を一元管理** — Production / Sandbox / Developer Edition / My Domain に対応
- **検索** — 組織名・ユーザー名・グループ名でリストを絞り込み
- **グループ管理** — 組織をグループに分類。ドラッグ＆ドロップで並び替え、クリックで折りたたみ
- **ユーザー名・パスワードのコピー** — 組織名クリックでコピーメニューを表示
- **暗号化保存** — AES-GCM-256 + PBKDF2-SHA256 でローカルに暗号化保存。クラウド送信なし
- **マスターパスワード** — 有効にすると、解錠しないと組織情報にアクセス不可。設定画面から有効化/無効化・変更が可能。ブラウザを閉じると自動ロック
- **インポート/エクスポート** — 全組織をJSONファイルで書き出し・読み込み
- **組織情報の自動取得** — ログイン後に Organization ID と API バージョンを自動保存
- **備考欄** — 各組織にメモを追加可能
- **テーマ切替** — ライト / ダーク / ブルー / フォレストの 4 テーマ
- **多言語対応** — 日本語 / English
- **ログイン先を選択** — 新しいタブ / シークレット / 新しいウィンドウ

## インストール

現時点では Chrome Web Store には公開していません。開発者モードで読み込みます。

### ビルド済みの場合

1. このリポジトリをクローン
2. `dist/` フォルダを用意（ビルド手順は後述）
3. Chrome で `chrome://extensions/` を開く
4. 右上の「デベロッパーモード」を有効化
5. 「パッケージ化されていない拡張機能を読み込む」で `dist/` フォルダを選択

## 使い方

### 初回設定

1. ツールバーの拡張機能アイコンをクリック
2. マスターパスワードを設定（8 文字以上）
3. ⚙ ボタン → 組織を追加

### 組織の登録

| 項目 | 内容 |
|------|------|
| ラベル | 表示名（例: 本番環境） |
| グループ | 分類用のグループ名（省略可） |
| 種別 | Production / Sandbox / Developer Edition / My Domain |
| My Domain URL | 種別が My Domain の場合に入力（例: `https://example.my.salesforce.com`） |
| ユーザー名 | Salesforce のログイン ID |
| パスワード | Salesforce のパスワード |
| 備考 | 自由メモ（省略可） |

### ログイン

組織リストの各行にある以下のボタンをクリックします。

| ボタン | 動作 |
|--------|------|
| ↗ | 新しいタブでログイン |
| 👓 | シークレットウィンドウでログイン |
| ⧉ | 新しいウィンドウでログイン |

ログイン後、Organization ID と API バージョンが自動的に組織情報へ保存されます。

組織名をクリックするとメニューが開き、ユーザー名・パスワードをそれぞれコピーできます。

### 設定（⚙）

| 項目 | 内容 |
|------|------|
| 言語 | 日本語 / English を切替 |
| テーマ | ライト / ダーク / ブルー / フォレストを切替 |
| セキュリティ | マスターパスワードの有効化/無効化、有効時はパスワード変更 |
| データ管理 | 全組織をJSONファイルへエクスポート / JSONファイルからインポート（既存データは維持） |

## セキュリティ

- 認証情報はすべてローカルの `chrome.storage.local` に**暗号化して保存**します
- 外部サーバーへのデータ送信は一切ありません
- マスターパスワードは `chrome.storage.session`（揮発メモリ）にのみ保持。ブラウザ終了時にクリアされ、ディスクには保存されません
- 暗号化方式: **PBKDF2-SHA256**（210,000 回反復）で鍵を導出し **AES-GCM-256** で暗号化
- **マスターパスワードを有効にした場合のみ**認証情報が実質的に保護されます。無効時は固定の内部鍵でエンコードされます（デフォルトは無効）
- ブラウザを閉じると自動でロックされます（マスターパスワード有効時）

> **注意**: 本ツールは非公式の個人利用向けツールです。Salesforce 社とは無関係です。

## 開発

### 必要環境

- Node.js 26+（[mise](https://mise.jdx.dev/) 推奨）
- pnpm

### セットアップ

```bash
git clone https://github.com/kazuya-s/sf-login-tool.git
cd sf-login-tool
pnpm install
```

### 開発ビルド（ウォッチモード）

```bash
pnpm dev
```

### 本番ビルド

```bash
pnpm build
# dist/ に拡張機能一式が生成されます
```

### テスト

```bash
pnpm test
```

### 技術スタック

| 分類 | 技術 |
|------|------|
| UI | React + TypeScript |
| ビルド | Vite + @crxjs/vite-plugin |
| 暗号化 | WebCrypto API (PBKDF2 + AES-GCM) |
| ストレージ | chrome.storage.local / session |
| テスト | Vitest |
| 対象ブラウザ | Chrome / Chromium（Manifest V3） |
